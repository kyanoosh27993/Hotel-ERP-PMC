## انجام‌شده
1. **برند:** حذف کامل آسا/asa از کد/کلاس‌ها/فایل‌ها/مستندات → Hotel-ERP (کامیت 972ebe7).
2. **انواع اتاق (فاز ۱۴ — اتاقها.zip):** فرم کامل انواع اتاق (نرخ ۴گانه ریال/دلار + پیک ۱-۳ + فول برد + تخت اضافه)،
   مشخصه‌های اضافی، اتاق‌ها با فیلترها، ستون‌های زندهٔ «تعداد اتاق / تعداد پر / تخت اضافه» با drill-down کلیک.
3. **پلان تور/شرکت (فاز ۱۵ — پلان.zip):** کدینگ درآمدی + لیست پلان‌ها + جزئیات با سهم «میهمان / تور-شرکت» +

4. **فولیو:** هر قلم کد درآمدی + مسیر دارد؛ **رجیستر:** انتخاب پلان.
5. **فازبندی منوهای پذیرش** (۲۲ عکس): PHASES.md موج ۸ — هر عکس یک فاز (R8-1..R8-14) با وضعیت هر بخش.
