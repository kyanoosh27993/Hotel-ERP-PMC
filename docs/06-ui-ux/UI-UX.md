# سند ۰۶ — راهنمای UI/UX دوزبانه

> فاز ۰ — قواعد تجربه کاربری. هسته‌های اجراشده در v0.1 (شل RTL، تقویم شمسی، ۳ تم، DataTable)
> الگوی مرجع ادامه کارند.

## ۱. اصول بنیادین

1. **زبان پیش‌فرض انگلیسی (LTR)** + فارسی کامل (**RTL**)؛ جهت چیدمان با `dir` استاندارد وب؛
   هیچ متن چسبانده‌شده‌ای جهت‌ثابت ندارد.
2. **موبایل‌اول:** اپ کارکنان/PDA روی گوشی و دستگاه دستی طراحی می‌شود، دسکتاپ ثانویه است.
3. **اعداد:** نمایش دو-زبانه (ارقام فارسی در FA، لاتین در EN)؛ ورود هر دو پذیرفته شود؛
   جدول‌ها `tabular-nums` برای تراز عمودی.
4. **تقویم:** شمسی در FA (الگوریتم jalaali تا سال ۱۵۰۰+، کبیسه صحیح) و میلادی در EN؛
   ورود تاریخ هردو گونه؛ ذخیره UTC.
5. **دسترس‌پذیری:** کنتراست AA، برچسب همه کنترل‌ها، ناوبری کیبورد کامل، حالت موبایل ۳۹۰px.

## ۲. ساختار ناوبری (دسته‌بندی طبق الزام کارفرما)

```
┌── فرانت آفیس ──────────────┬── بک آفیس ─────────────────┐
│ پذیرش | رزرواسیون | صندوق   │ داشبورد مدیریت | گزارش‌ها    │
│ رستوران(POS) | خانه‌داری      │ حسابداری | مالی و دارایی    │
│ لاندری | تشریفات | تلفن      │ انبار و کاست کنترل | خرید    │
│ فروشگاه(+اینترنتی) | مصارف   │ منابع انسانی | حقوق          │
│ درخواست‌ها | خدمات مشتری     │ مؤدیان و مالیات‌ها           │
│ باشگاه/کلوپ | مکاتفات/بایگانی│ مدیریت درآمد و هزینه        │
│ اندیکاتور | آبی‌شارژینگ      │ هوش مصنوعی و داشبورد تلفیقی │
│ آرشیو اسناد | کارپردازی      │ سیستم و تنظیمات             │
│ کی‌کارت | پارکینگ | تاکسی     │ (ماژول‌ها دسته‌بندی‌شده)     │
└─────────────────────────────┴─────────────────────────────┘
```

منوی کناری جمع‌شونده (همبرگری در موبایل)، جستجوی فرمان‌محور (Ctrl+K)، نان‌خرد مسیر.

## ۳. قطعات مشترک (Component Library)

- **DataTable استاندارد** (الگوی موجود v0.1): هدر جستجوپذیر، سورت، فیلتر، سطر جمع پویا،
  ریسپانسیو، shrink-to-fit؛ همه فهرست‌ها از همین قطعه.
- فرم‌ها: اعتبارسنجی درجا، پیام خطا دوزبانه کنار فیلد، ذخیره غیرفعال تا اعتبار.
- مودال تأیید برای عملیات‌های برگشت‌ناپذیر مالی (با متن پیامد + نیاز به تایپ کد).
- اعلان‌ها: toast برای موفقیت، بنر ماندگار برای خطا، مرکز اعلان برای رویدادها.
- نمایش پول: هزارجداکننده + واحد ریال/تومان (تنظیم کاربر)؛ هرگز گردکردن در UI.

## ۴. تم و پوسته

سه تم (روشن/تیره/سازمانی) + شخصی‌سازی فونت جدا متن/عدد — الگوی موجود v0.1. رنگ‌های وضعیت:
موفق/هشدار/خطا/خنثی؛ رنگ برند در عملیات اصلی؛ پرهیز از اشباع بالا در سطوح بزرگ.

## ۵. صفحه‌های کلیدی و استانداردهای هرکدام

| صفحه | استاندارد پذیرش |
|---|---|
| تقویم اشغال (رزرواسیون) | نمای روز/هفته/ماه + رنگ وضعیت + درگ‌اند‌دراپ تخصیص |
| فولیو مهمان | تفکیک شارژ/پرداخت، مانده لحظه‌ای، چاپ/ایمیل |
| POS رستوران | نقشه میز، حذف حداقل کلیک، میان‌بر صفحه‌کلید، آفلاین‌پذیر |
| PDA سفارش | تک‌دست کاربرد، دکمه‌های بزرگ، اسکن QR، همگام‌سازی خودکار |
| داشبورد نقش‌محور | KPI بالای صفحه، نمودار تعاملی، هر عدد با منبع (drill-down) |
| سند حسابداری | نمایش ۱۴ فیلد، گردش تأیید، تفاوت‌نمای بین نسخه‌ها |
