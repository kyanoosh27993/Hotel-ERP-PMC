# راهنمای نصب نسخه اندروید (Hotel-ERP-Android.apk)

> اپ اندروید همان شل وب کامل است که داخل WebView بسته‌بندی شده (Capacitor). اپ به سرور روی شبکه وصل می‌شود — یعنی نسخه ویندوزی باید روی همان شبکه (Wi-Fi) اجرا باشد.

## نصب

1. از [صفحه Releases](https://github.com/kyanoosh27993/Hotel-ERP-PMC/releases) فایل `Hotel-ERP-Android.apk` را دانلود کنید (در گوشی یا با کابل منتقل کنید).
2. هنگام نصب، اندروید می‌پرسد «اجازه نصب از این منبع» → Allow (APK تستی با امضای debug است).
3. اپ «Hotel ERP» نصب و باز می‌شود — رابط فارسی RTL با تقویم شمسی.

## اتصال به سرور

اپ به‌تنهایی دیتابیس ندارد؛ باید به کامپیوتری که `Hotel-ERP-Windows.exe` (یا docker compose) روی آن اجراست وصل شود:

1. روی کامپیوتر: `ipconfig` → IPv4 مثلاً `192.168.1.50` (همه دستگاه‌ها یک Wi-Fi)
2. فایروال ویندوز پورت 3000 باز باشد (پنجره Allow اولین اجرا، یا دستور در راهنمای ویندوز)
3. در اپ: ماژول **داشبورد مدیر AI** → کادر «آدرس API» را `http://192.168.1.50:3000/api/v1` بگذارید → دکمه اتصال (توکن با `admin` / `Admin@Hotel1` — طبق راهنمای ویندوز)

تنظیمات در گوشی ذخیره می‌شود؛ دفعه بعد مستقیم وارد می‌شود.

## نکات

- امضای debug برای تست است؛ نسخه امضاشده رسمی در فاز انتشار ساخته می‌شود.
- اگر اپ به سرور وصل نشد: فایروال، یکسان بودن Wi-Fi و درستی IP را چک کنید.
- برای تست بدون سرور، ماژول‌های محلی (تقویم شمسی) کار می‌کنند.
