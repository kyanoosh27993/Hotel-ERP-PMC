**قانون:** هر سناریو یک ردیف ثابت. شش چک مالک به‌عنوان ستون ثابت:
- **دکمه** = کلیدها/جریان‌ها کار کنند
- **ذخیره** = داده عیناً همان ورودی ذخیره شد (خواندن مجدد)

- **محاسبه** = اعداد درست (در برابر DB مستقیم)
- **نمایش** = داشبورد/لیست با DB هم‌خوان
- **یکپارچه** = زنجیرهٔ ماژول‌ها بدون شکست
