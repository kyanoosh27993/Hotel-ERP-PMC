# راهنمای نصب نسخه ویندوز (Hotel-ERP-Windows.exe)

> یک فایل exe — بدون نصب، بدون Docker، بدون Node.js. دیتابیس PostgreSQL به‌صورت جاسازی‌شده داخل خود برنامه اجرا می‌شود.

## نصب و اجرا

1. از [صفحه Releases](https://github.com/kyanoosh27993/Hotel-ERP-PMC/releases) فایل `Hotel-ERP-Windows.exe` را دانلود کنید (نسخه v0.4.0 یا بعدتر).
2. فایل را در یک پوشه قرار دهید (مثلاً `C:\HotelERP`) و دابل‌کلیک کنید. **نیازی به «نصب‌کننده» نیست.**
3. اولین اجرا حدود ۳۰–۶۰ ثانیه طول می‌کشد (ساخت خوشه دیتابیس + داده اولیه). پنجره کنسول باز می‌ماند — این پنجره **سرور برنامه** است؛ بستنش = خاموش شدن برنامه.
4. مرورگر به‌صورت خودکار روی `http://localhost:3000` باز می‌شود. اگر باز نشد، آدرس را دستی باز کنید.
5. SmartScreen ویندوز ممکن است هشدار بدهد (برنامه امضای دیجیتال ندارد) — «More info» → «Run anyway».

## داده‌ها کجاست؟

- پوشه داده: `%APPDATA%\HotelERP` (دیتابیس، لاگ‌ها، رمزها)
- برای شروع از صفر: پنجره برنامه را ببندید، پوشه بالا را پاک کنید و دوباره اجرا کنید.

## کاربران اولیه (نسخه تست — MFA خاموش)

| کاربر | گذرواژه | نقش |
|---|---|---|
| `admin` | `Admin@Hotel1` | مدیر سیستم (همه دسترسی‌ها) |
| `frontdesk` | `Admin@Hotel1` | پذیرش (رزرو/اتاق/POS) |
| `accountant` | `Admin@Hotel1` | حسابدار (اسناد/حقوق — بدون دسترسی اتاق) |
| `approver` | `Admin@Hotel1` | تأییدکننده مالی |

در استقرار واقعی (docker compose) نقش‌های حساس MFA دارند؛ در نسخه دسکتاپ تست برای سادگی خاموش است.

## تست با موبایل روی همان Wi-Fi (اختیاری)

1. IP دسکتاپ را بگیرید: `ipconfig` → مثلاً `192.168.1.50`
2. در ویندوز برای پورت 3000 مجوز دهید (اولین اجرا پنجره Firewall می‌دهد → Allow) یا:
   `netsh advfirewall firewall add rule name="HotelERP" dir=in action=allow protocol=TCP localport=3000`
3. در اپ اندروید → ماژول **تنظیمات** → آدرس API: `http://192.168.1.50:3000/api/v1`

## تست پیشنهادی (دروازه M4)

- داشبورد مدیر AI → ورود admin → اعداد از کوئری واقعی
- **نقشه اتاق** → تغییر وضعیت اتاق به «خارج از سرویس» با دلیل → ظرفیت همان لحظه کم می‌شود
- رزرو گروهی (units=10) با تعرفه ویژه → رزرو هم‌پوشان دیگر ۴۰۹
- چک‌این → اتاق خودکار تخصیص می‌شود → چک‌اوت → اتاق «نیازمند نظافت»
- لیست انتظار → تبدیل به رزرو
- حسابدار → PATCH وضعیت اتاق باید ۴۰۳ بگیرد

## رفع اشکال

- **پورت اشغال:** `set PORT=4000` و بعد اجرا، یا `HOTEL_PG_PORT=5438`
- **خطای دیتابیس:** پنجره را ببندید، `%APPDATA%\HotelERP\pgdata` را پاک کنید، اجرای مجدد (مهاجرت‌ها دوباره اعمال می‌شود)
- لاگ کامل: `%APPDATA%\HotelERP\pg.log` و کنسول برنامه
