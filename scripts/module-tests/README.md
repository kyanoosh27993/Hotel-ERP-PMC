# رجیستری تست‌های ماژولی (لایه ۱)

هر فایل `0N-<module>.mjs` یک تست عمودی ایزوله برای یک ماژول است.

## قواعد اجرا (ضد سردرگمی و ضد اخلال زبانی)

1. **هر اسکریپت فقط یک ماژول را تست می‌کند** — خروجی PASS/FAIL کوتاه + شمارش.
2. **هر اسکریپت خودش reset/truncate فقط جداول همان ماژول را انجام می‌دهد** (نه کل DB).
3. **ترتیب اجرا:** ۰۱ → ۰۹ (وابستگی از پایین به بالا). هر اسکریپت مستقل است ولی اگر ردیف قبلی دادهٔ وابسته می‌سازد، آن را به‌جای truncate مجدد، reuse می‌کند.
4. **زبان:** همهٔ اسکریپت‌ها JS (ESM) با `pg` و `fetch`. منبع تولیدی نیست.
5. **هنگام دیباگ:** فقط فایل اسکریپت + `apps/api/src/<module>/` را باز کن. به هیچ فایل Python/وب/ماژول دیگر دست نزن (نگاه به `docs/lang-map.md`).
6. **خروجی استاندارد:** هر اسکریپت در انتها چاپ کند:
   ```
   0N-<module>: <N>/<N> PASS — <M> FAIL — FINDINGS: [key, ...]
   ```

## اجرا
```bash
# تک ماژول
node scripts/module-tests/02-pms.mjs
# همهٔ ماژول‌ها به ترتیب
for f in scripts/module-tests/0*-*.mjs; do node "$f" || break; done
```
